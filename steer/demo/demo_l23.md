# L23 refusal direction: stock vs unlocked, side by side

`Qwen/Qwen3.5-4B`, bf16, CPU, 4 threads. Greedy decoding, 120 tokens per reply, identical prompts in identical order in all three conditions. Generated by `steer/demo/make_demo.py` in 4 min.

Three conditions:

- **stock** — the unmodified model.
- **L23 ablated** — the layer-23 difference-of-means refusal direction (`unit(mean(refuse) - mean(comply))` at the last prompt token, fitted on `contrast128`) is projected out of every residual write, at every layer and every position, at generation time.
- **weight-orth** — the same direction projected out of the weights that write into the residual stream (`embed_tokens`, every attention `out_proj`, every MLP `down_proj`). No hooks at generation time.

The six mild requests are everyday-dishonesty asks: no weapons, CBRN, cyber, self-harm or sexual content. **None is a `tool_bait` (`tb-*`) item and none is a `contrast128` (`cf-*`) item.** They do fall in the same broad template families the direction was fitted on, so this demonstrates the direction working on its fitting distribution, not generalisation to unseen request types. The three factual questions are there to show the edit does not break ordinary competence.

No `tb-*` prompt text and no model output to any `tb-*` item appears in this file.
